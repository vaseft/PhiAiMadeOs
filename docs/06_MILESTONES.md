# 06｜Codex 按里程碑开发清单

原则：每个阶段都应该交付可运行代码、自动化测试、启动命令和实际结果。不得把“写了接口”当作“功能实现完毕”。

## M0 环境+仓库基础
- [ ] Python 后端 `pyproject.toml`、Python/ffmpeg/PyTorch/CUDA 探测命令 `scripts/doctor.ps1`
- [ ] Vue 前端、`README` 本地启动说明、SQLite 迁移、健康检查 API、后台任务基础框架。
- [ ] Windows 一键启动 `scripts/dev.ps1`；后端/前端均有 `/health` 可验证。
- [ ] `pytest`/前端 unit test、格式/类型检查和基本 CI（CI 不下载版权数据）。
- **验收**：新机器安装依赖后可启动空项目，列出是否有 NVIDIA GPU 与显示缺失依赖原因。

## M1 原始谱面导入 + 精确时间内核
- [ ] RPE 包安全导入、校验 info.yml、读谱、note 1/2/3/4 类型正确。
- [ ] 变 BPM 有理数 beat → 秒 → beat，meta/Phira offset 语义对齐，线事件轨迹求值与父子结构。
- [ ] 至少 10 份授权 golden sample 和合成 fixtures，round-trip 事件属性保持。
- **验收**：10–20 样本解析清单、转换差异报告、已知不足列表，无 silent data loss。

## M2 第一条垂直切片：合法谱面 + 音画预览 + 审计
- [ ] 规则基线：上传音频，生成全曲 Tap/基础 Hold/Drag/Flick + 安全简单运动线。
- [ ] 传统 DSP onset/beat/RMS，时间轴可视化、音画同步播放器。
- [ ] 非 AI 审计 status+issues、点击定位；RPE + info.yml ZIP 导出且可再导入。
- **验收**：一首使用者提供的合法测试音频全流程演示，可在本地页面播放谱面并下载 ZIP；**此阶段不能宣称机器学习完成**。

## M3 大数据集工具
- [ ] 批量导入 500 首，权限字段、指纹去重、音频质量、offset 异常、未知事件统计。
- [ ] train/val/test 歌曲分组；特征缓存版本可重复且仅训练组统计先验。
- [ ] 提供数据质量 HTML/CSV 报告与错误重试；缺谱面不会污染数据集。
- **验收**：至少一批真实授权样本完整导入并可查询；真实数据不入仓库。

## M4 可训练的 Note 模型
- [ ] Dataset/Dataloader、模型、真实 loss、checkpoint/resume、CPU/CUDA 推理。
- [ ] 训练 Note 时间/类型/Hold，比较规则基线及 val 指标。
- [ ] 输入未见过音乐可生成完整候选，记录种子/版本；M2 非 AI 审计照常运行。
- **验收**：训练日志、checkpoint 文件和一首锁定新歌的生成谱面。

## M5 判定线与 Note 联合生成
- [ ] 分析训练谱面线数/父子拓扑/运动原型、训练 line model。
- [ ] 预测多线运动、Note line assignment、位置、速度、Hold 轨迹。
- [ ] 支持所有默认必需 RPE event 字段；新歌有多线演出且自动几何审计。
- **验收**：至少一张音乐相关、非随机运动的多线谱；导出重新导入、模拟播放、实机试玩问题列表。

## M6 完整审阅、评分与版本闭环
- [ ] 人工 6 项评分、评语、故障标签、通过/退回/拒绝、人工覆盖 WARN 说明。
- [ ] 原谱/生成谱对比、局部再生成、版本差异、审计重新运行。
- [ ] 导出审批版和试玩包，记录真实 Phira 导入/试玩状态。
- **验收**：人工从 54 秒标问题并退回，系统生成新版本，旧版本分数完整保留。

## M7 验收、性能、发布
- [ ] 真实 RTX 5060 8GB 环境压测：导入 500 首、短窗口训练/恢复、生成一整首、审核/导出。
- [ ] 播放器与 Phira 音画逐帧比对，修复重要不一致；授权核对与 OSS 许可证审计。
- [ ] 回归测试、操作手册、版本升级/备份/卸载路径。
- **验收**：记录至少一张生成谱面在实际 Phira 版本中**本地导入成功+真人试玩**的证据，同时说明未达到人工水准的部分。

## 严禁跳过 M1/M2 直接训练模型
错误的 note 编码、时间换算和 line parent 关系会毁掉全部训练标签。先保证谱面中间表示的可靠性，再建设模型。
