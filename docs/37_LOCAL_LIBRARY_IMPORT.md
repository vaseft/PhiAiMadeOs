# 用户提供谱面库的本地导入

用户明确提供本机 `官方谱面` 目录后，可以导入其 ZIP/PEZ 资产。**下载完成不自动代表训练或分发授权**；入库统一记录 `license_status=unknown`、仅 `local_research`，对齐与试玩未确认。导入不训练、不调用外部 API、不上传素材或权重。

## 入口

在已部署环境中执行：

```bat
.venv\Scripts\python.exe scripts\import_local_library.py "E:\PhiAiMade\官方谱面"
```

这是明确指定目录的本机管理入口，网页不能提交任意磁盘路径。程序不会跟随目录软链接/联接点，不会覆盖源包；逐包登记原始 SHA-256、原始谱面成员、音乐、曲绘、元数据、转换结果与限制。原包留在来源目录，原始谱面成员按字节提取保存；转换结果另存。相同源包可重跑去重，音乐按精确文件 SHA 去重；不宣称已识别不同编码/裁切的同曲。

每批在 `data/imports/<run_id>/` 保存数据库在线一致性备份、进度和报告。记录与相关资产逐包原子入库，失败项明确列出；取消/中断保留已完整登记的包，可重跑继续。不要在运行中的工作台上直接覆盖数据库备份。

## 格式与状态

- 原生 Phigros JSON `formatVersion=1/3` 使用独立适配器，依据锁定 Phira-Pro 的 `prpr/src/parse/pgr.rs` 与 RPE 解析语义进行映射。转换结果用于工作台参考预览，不代表已完成客户端格式/可玩性认证。
- 保留原生每线 BPM 的时间比例与原始 offset；RPE 拍坐标统一到参考 BPM，不能将其描述成从音乐测得的全曲 BPM。
- 原始 Note 类型与 RPE 枚举不同，必须显式映射；原始坐标、速度、旧版打包运动坐标、事件空档/重叠有独立处理和来源记录。无法正确表达的特殊机制拒绝转换并保留原件。
- `ready` 表示解析并建立工作台候选，不表示审计/人工审核/试玩通过。候选仍为 draft。
- `archived_only` 表示原谱与可识别媒体入库，但当前方言或转换能力不足，禁止伪造预览候选。PEC/PBC 暂不转换；原始内容保留并报告原因。
- 单条 `info.csv` 可明确关联主谱面、音乐和封面；CSV 全局设置和 `line.csv` 外置判定线图片尚未映射，此类包仅存档，附加图片/配置仍完整保留在原包。
- ZIP 的路径、数量、展开体积、压缩方式/比例、加密、特殊文件、CRC 和实际读取长度受约束。损坏或无法唯一关联资源的包会失败，不猜测绑定。元数据引用错误但实际只有唯一文件时，可以恢复关联并留下明确告警与原引用。

原始 `source_level` 原样展示，例如小数定数与特殊难度；不把 Legacy/SP/BND 硬归入常规等级。不自动舍入小数到模型条件：缺少完整 canonical 类别和合法整数值时，训练难度保持未标注。人工可在标签页单独确认；原始级别保留。

## 后续使用

### 大谱面与时序补处理

读取/导出统一使用256 MiB JSON、2400万节点、64层嵌套的有界预算，原生事件100万、转换后事件200万。预算仍会明确拒绝更大输入，但不再把此前32 MiB/200万节点/10万事件当作官谱容量。只读 IR 借用单一快照，预览只保留一份经过哈希校验的候选缓存，返回当前时间窗内事件及其前置生效锚点；原文件和完整事件不会被预览抽样修改。

原生反向事件按锁定 Phira-Pro 的忽略规则处理，完整原值、原索引、动作与告警保留。少数原生 height 的最后终点早于作者后续流速帧；转换保留末音符/Hold结束后1秒之前的原顺序函数，在该边界内插后冻结。此边界之后的原客户端行为可能依赖游标/seek历史，不能宣称整条时间轴与任意seek等价，受影响原始帧和事件完整留痕。

对已经登记、此前受容量或时序限制的存档执行：

```bat
.venv\Scripts\python.exe scripts\reprocess_local_library.py
```

补处理先备份数据库，逐份校验原包与原谱哈希，以新候选登记结果，保留原始路径/字节、旧状态与原因、现有人工标签和授权；候选与素材指针在同一CAS事务更新。不会重新提取音乐或生成新的素材身份；仍不支持的机制更新为实际剩余原因。任务可取消，已成功记录保留。

素材库可按名称查询，`ready` 的谱面可以进入审核页查看参考时间轴，原音乐通过已绑定本地资产播放。完整 DSP 分析仍由用户单独启动；导入不假装已完成音频审计。

训练需要音乐和谱面分别有明确 training 授权、歌曲簇、人工对齐、模型可表达的标签与事件。自动 `group_method=exact_audio_bytes_only` 仅表示音频字节一致，不满足人工歌曲簇门槛；须在标签页明确填写涵盖转码、剪辑及不同难度的歌曲簇 ID。`official` 只记录用户来源声明，不能替代许可，也不再继承早期“尚未提供目录时禁止读取”的临时条件。即使以后获得许可，复杂谱面仍可能因当前模型的线数、事件、控制字段或窗口容量限制被拒绝。

本轮按用户之前“测试以外”的要求仅进行真实数据导入、静态解析和生产打包。格式往返、客户端回放、训练与 GPU 峰值均 **NOT RUN**。本机作品和全部源素材继续被 Git 忽略；代码经 feature 分支与 Draft PR 提交，不能将导入操作当成验收通过。
