# 验证停滞后的本地自动换源

用户明确要求“训练多轮没有成效自动替换训练源”。此功能受简洁窗口“无改善自动换源”开关控制，和“自动继续”分别保存；不下载外部训练素材，不扩大既有授权范围。

## 触发与选择

- 某训练阶段的已完成轮数减最佳验证轮数达到8，或已触发原训练器早停，视为换源条件；判断使用当前数据阶段的独立歌曲簇宏平均验证损失，不用训练损失或保留集选择来源。
- 完整一轮结束后选择已在本机数据库登记、manifest SHA一致且不超过128MiB的来源；重新核对每份训练/验证素材当前的明确训练许可和父模型覆盖模式。候选优先按新增训练内容数、总样本数排序。
- 训练内容身份由谱面ID、谱面文件SHA和特征SHA构成。必须包含历史训练链尚未用过的内容；只改manifest ID、重复导入或返回旧来源不构成新内容。
- 比对所有历史来源中的歌曲簇/来源组、音频资产、音频SHA和特征SHA，任何历史train/val/test归属变化均拒绝，包括把已训练歌曲变成新验证集。特征版本、拆分版本与随机种子也须兼容。
- 没有兼容的新来源时关闭自动继续并显示原因；不为保持运行而循环换同一批，也不丢弃受限样本来凑新来源。

## 模型与进度

- 换源创建新的run_id和数据阶段，不在旧运行中改manifest或绕过恢复哈希检查。父运行的模型/曲线、每轮前快照及注册表保留，结果仍为experimental。
- 只加载父运行各阶段经过SHA与架构核对的最优权重，重建优化器、调度器和scaler，轮数从1开始；原运动原型字典保留，避免同一原型ID含义变化。初始化来源及权重SHA、完整来源链与数据SHA写入新运行元数据。
- 新闻件尚在CPU索引时，控制器使用已登记的待执行请求展示来源、进度与暂停；此时暂停不创建成功模型，重试保留目标运行ID。产生断点后按新运行恢复，不重新从父权重开始已训练阶段。
- 窗口显示当前数据阶段/谱面数，并提供当前/历史阶段曲线选择；每一阶段的验证集合可能扩大，曲线与改善百分比独立计算。
- 暂停会关闭自动继续；换源开关保留为下次设置。关闭换源开关时，旧训练器的早停仍会停止自动继续。服务中断后不自动重启被中断任务。

## 本机实际核对与验收边界

当前24曲来源与已登记356份全库候选之间，24份共享谱面和全部交叉身份没有拆分冲突；全库划分为289训练/36验证/31保留，相对历史训练内容新增271份。特征/拆分版本和种子一致，素材当前许可允许本机训练。候选规划仅处理身份、权限和来源元数据，没有读取保留集原谱/特征参与选择。

本次完成TypeScript/Vite生产构建、5份改动Python源码AST静态解析、真实候选规划和提交前安全检查。控制器部署保留原自动继续偏好，并按用户本次要求启用换源开关；部署前让原当前轮正常完成，避免硬终止训练。实际最终状态以本机任务/交付记录为准。

没有人为修改损失或轮数来触发换源，没有为专项验证启动全库训练；跨源初始化/异常恢复、暂停、所有数据模式和长期资源验收均 **NOT RUN**。既有CI不代替新功能专项验收，增加数据不保证模型效果提高。

代码可用revert回退到本次功能前的`6cc241b`；回退代码不自动改写本机训练状态。若已切换来源，先暂停并备份状态，再选择保留的父运行/模型；禁止训练中覆盖manifest或检查点。
