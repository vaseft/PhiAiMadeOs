# PAMOs 本地审批桥接

独立实现，GPL-3.0-only；只依据 rpe-next 公开 API 1 声明，不包含其 PolyForm-Noncommercial 实现代码。参考 commit `740fe7ebaa04506f26fdec4e37794f97da1fcf4d`。

1. 运行根目录 `Start-PAMOs.cmd`，再运行 `Open-RPE-Next.cmd`。
2. 在工作台下载 `.rpenmod`；编辑器“模组”中导入、查看源码并手动启用。
3. 在编辑器先打开需要修改的谱面；工作台生成配对码后，粘贴到模组面板。
4. 模组把谱面 JSON 快照发送到本机，工作台创建独立候选；在此候选上生成局部建议、看 diff、批准、提交、独立审计并人工评分。
5. 工作台“发送到编辑器”只接受本次快照的已审核修订。编辑器先比较源快照哈希，再使用公开 `commit()`、`save()`。只有真实完成保存且 `dirty=false` 才返回 `SAVED`。

WebSocket 固定为 `ws://127.0.0.1:8765/api/v1/bridge/ws`；配对码只在内存保存、一次使用、5 分钟失效。不会传送音频、曲绘或任意本机路径。编辑器若有手工改动，会拒绝覆盖；重新配对后从新快照开始。保存失败不覆盖源文件、不伪造成功；已进入编辑器撤销历史的修改可以由用户撤销。

当前只允许本机网页编辑器 `http://127.0.0.1:4173` / `http://localhost:4173` 的 Origin。桌面旧 RPE、其他端口和其他上游版本未认证。编辑器模组没有权限沙箱，启用即信任源码；此桥接代码尚未执行实机验收（NOT RUN）。
