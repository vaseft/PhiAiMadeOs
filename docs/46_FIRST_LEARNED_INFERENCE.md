# 首次新音乐整曲学习式推理

2026-10-25，用户要求使用本地已训练模型，为新导入的自有AI音乐试生成整曲谱面。素材与产物仅存本机，本文只保存去标识化结果。此任务实际执行模型推理与独立审计，不以训练loss替代成品验收。

## 输入和模型

- 音乐144.0135秒、48kHz双声道，源SHA核对一致，已登记本地创作用途。精确相同音频的所有资产ID与当前356份及父24曲的训练来源指纹均无交集。
- 使用356份来源最近完整登记的第15轮实验bundle；当前第16轮未完成的断点未冒充完整模型。各阶段使用登记的验证最优权重，Note最佳第12轮、Line第8轮、Placement第11轮。加载前核对架构、特征版本及三阶段权重SHA。
- 常规多线，目标IN15、演出强度45、节奏关联风格、狂野度25、可玩性优先、严格约束、seed42；全曲10个窗口，CUDA/BF16，不使用规则基线或外部LLM代替学习式结果。IN15为请求条件，实际难度没有人工认证。

## 真实结果

整曲成功生成1003音符、24判定线；1003音符全部为Tap，无Hold/Drag/Flick。平均约6.96音符/秒、峰值12；预测并整理后的运动事件788，含静态补全的IR总事件907。模型推理记录约1.344秒，整个最后一次任务约5.108秒；不包含首次特征准备时间，非普适性能保证。

独立审计为 **WARN**，确定性BLOCK为0；1003条yOffset几何覆盖提醒，保存前1000条并明确截断，未伪造已完整复现客户端几何。起音匹配窗口±80ms的启发式命中率约24.7%，已匹配锚点绝对误差中位数81ms、P90为181ms。该统计使用传统起音和一对一匹配，密集/近同刻音符会影响它；不是人工节奏分，也不能据此认定其余音符全错。

局部占用投影702次、重复运动预测去重2390次、运动交叠修整778次、连续性投影761次，全部已有推理修复日志，未移除原始素材或用规则新增音符。音符全部Tap、修复量较多和节奏证据表明模型仍存在明显质量局限。需要针对类型覆盖、时序与布局进行后续评估，不能宣布已经学会作出成熟谱面。

候选保持learned_experimental/awaiting_review；用户可以在工作台同步参考预览。未写人工评分、未提升candidate/stable、未绕过审核打包成发布谱。Phira-Pro真实导入/手打、完整双方言往返、全部模式及整体能力评估均 **NOT RUN**。

## 本次发现并修复的问题

工作台标准请求含 `noise_area: {generation_enabled: false}`，旧通用递归扫描将这个关闭能力声明误认成噪域数据。推理入口现在只接受精确、明确关闭的声明，其他启用/附带事件/嵌套噪域仍拒绝。生成谱面以独立关闭能力标志记录该元数据，完整请求和SHA保留在候选记录，避免下游误报为实际噪域。

原始数据/训练噪域保护、共同格式检测、缓存实现和模型参数均未改动。六项定向边界测试通过（其中启用/附带数据含子用例），两次候选judgeLineList数值完全一致，证明元数据修复未改动预测音符/线事件；最后一次真实生成和审计成功。最初失败任务与诊断候选保留，可追溯，不删除失败记录凑通过。
