# 桌面简洁训练窗口

双击仓库 `Start-PAMOs-Training.cmd` 打开独立 Edge/Chrome 应用窗口。界面保留“训练”“暂停训练”两个按钮、一条真实进度条和状态文字，按用户追加要求新增“自动继续”开关与三阶段训练/验证损失曲线；没有工作台导航或训练参数。已部署机器的桌面另有 `PAMOs训练.cmd` 指向此入口。

- 启动器复用本目录的回环工作台服务；服务未启动时隐藏启动，等待就绪再打开窗口，不自动训练。端口冲突或旧版服务会明确报错，不终止别的进程。
- “训练”优先绑定 `.local/simple-trainer.json`，首次沿用已有用户暂停记录指定的运行，缺省取本地最新可用模型；没有可恢复运行时不启动。不会因为全库新准备完成而替换现有数据集。
- 已完成运行每次点击增加一轮目标；暂停、失败或中断后保持原目标继续。沿用同一训练集、拆分、种子、模型与优化器配置，采用本机校准的运行批量；有效批量不匹配时保留原批量。
- “暂停训练”等待当前完整优化器批次或验证批次结束，原子保存模型、优化器、调度器、scaler、随机状态、epoch和窗口游标后退出worker并释放GPU。索引前或索引后也可暂停，尚未产生新计算时保留原断点。暂停只在worker确认后显示“已暂停”。
- 每次开始前校验数据集和检查点SHA，在本机 `data/training_backups/<run>/<snapshot>/` 保存清单和不可变检查点快照；同卷优先硬链接，失败回退复制。新权重仍为experimental，不自动提升、发布或上传。
- 自动继续默认关闭。空闲时开启将在下次点击训练后生效；训练中开启则当前轮完成后自动继续下一轮。开关在本机状态保存，关掉网页仍可在服务内继续；暂停会先关闭自动继续，失败、服务重启后的中断或1000轮控制上限都会停止自动续训。仅关闭开关时，当前轮会继续到结束。
- “无改善自动换源”独立控制：某阶段连续8轮未刷新验证最佳值，当前轮结束后选择含新训练内容、许可和历史拆分均兼容的登记数据源；新建运行并用父运行最优权重初始化，优化器重建、运动字典保留。没有新来源时停止，不在同批数据或副本间循环；关闭该选项则维持验证早停后停止的行为。详见 `42_AUTOMATIC_TRAINING_SOURCES.md`。
- 三阶段分别展示真实批次损失和独立歌曲簇宏平均验证损失，横轴为优化器步，不平滑或生成数据；显示最新验证值和较前一轮变化。训练下降、验证连续三次上升时提示“可能过拟合”，不直接判定生成质量。读取最近8MiB日志，每阶段最多600训练点/200验证点，截断明确提示，重复优化器步不重复统计。换源后重新计轮、曲线独立，可在数据阶段下拉框查看旧曲线，不把验证集合变化解释成模型改善。
- 重复点击或多个窗口不额外排队；GPU另有任务时禁用开始。关闭窗口不会取消训练；需要暂停请先点击暂停，等待状态确认。关闭工作台服务仍按原任务中断策略处理。

## 变更与验证边界

后端：`simple_trainer.py`、`training_analysis.py`、`api/app.py`、`jobs.py`、`worker.py`、`training.py`；独立前端：`trainer.html`、`trainer.ts`、`SimpleTrainer.vue`、`TrainingLossChart.vue`及Vite多页面构建；Windows入口：`Start-PAMOs-Training.cmd`、`scripts/launch_training.py`。复用现有同源、会话和CSRF保护；MCP令牌不能启动/暂停训练或设置自动继续。

生产构建 `npm.cmd run build` 实际完成（TypeScript检查及Vite多页面打包）；六个改动Python文件AST静态解析完成。提交前检查空白、文件列表、私有资产和凭据。构建及源代码检查不等于训练暂停/恢复验收。

本机已实际通过桌面CMD启动隐藏服务，服务报告startup complete；`trainer.html`返回HTTP200，受会话保护的状态接口返回已有运行complete/100%、允许训练/不允许暂停，当前无活动任务。打开窗口没有提交训练任务。启动过程兼容Windows空闲回环端口返回连接超时的情况，复用服务前核对所属根目录。

按用户此前“测试以外”的要求，没有新增或主动运行专项自动测试、自动续训/暂停恢复验收、浏览器视觉验收或客户端试玩，均 **NOT RUN**。部署后用户通过训练按钮提交第3轮续训，实际观察到原数据/拆分、8×2档位及真实进度推进；这个使用记录不替代控制专项验收。既有GitHub CI继续运行，结果以PR检查为准。

## 回退

通过 `git revert` 回退本次控制器和窗口提交可恢复原工作台入口；本机数据不随Git回退。恢复某次训练快照需先暂停训练并停止工作台，备份现状后按 `snapshot.json` 指向的原运行目录恢复对应manifest和阶段文件（原清单中的相对路径应保持一致）；不删除新版本权重或旧模型登记。不在训练运行时覆盖清单。
